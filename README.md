# LiveSoundFix

面向 **A7C2 等相机在中小型 Livehouse 单点录音**的本地后处理工具：修复削波/底噪/交流声、重建中低频与高频、抑制混响、扩展声场、母带响度达标。

全部算法用**纯 numpy + 标准库**实现，零云端、零外网依赖、无 scipy / torch。

| | |
|---|---|
| 运行形态 | 本地 HTTP 服务 + 单页 UI（`http://127.0.0.1:8765/`） |
| 依赖 | `numpy`（唯一硬依赖）；可选 `ffmpeg`（读 mp3/m4a/mov/mp4 时用） |
| 处理链 | 9 段固定顺序，逐段可开关、可调干湿比、可调音台推子 |
| 版本 | **v1.1.4** —— 更新内容见 [CHANGELOG.md](CHANGELOG.md) |
| 许可证 | [MIT](LICENSE) |

---

## 功能

- **文件诊断**：LUFS / LRA / 峰值 / 削波占比 / 相关度 / 噪底 / 高频截止 / 市电频率 + 问题列表与参数建议。
- **9 段处理链**：`sep → ai → m5 → m1 → m2 → m3 → m4 → m6 → dyneq`，逐段开关、独立干湿比、调音台推子实时重混。
- **三区单页 UI**：左列诊断与处理链；右上实时频谱 / 波形；右下拖拽 EQ + 调音台推子。
- **即时 A/B 对比**：处理后与原片两轨同播，切换只做 6 ms 增益交叉，无换源、无 seek、无延迟。
- **进度与 ETA**：异步作业 + 分段成本模型，逐块反馈。
- **导出**：stereo / mono / 5.1，16 / 24 / 32 bit float，可选 LUFS 归一与真峰保护。
- **缓存与回收**：解码 / 统计 / 转码三层缓存；`cache/` 分类统计、按容量与天数自动回收。

## 运行方法

```powershell
git clone https://github.com/Naiyalatuotip/LiveSoundFix.git
cd LiveSoundFix
python run.py                 # 浏览器自动打开 http://127.0.0.1:8765/
```

其他参数：

```powershell
python run.py --port 9000 --no-browser   # 自定义端口、不自动开浏览器
```

基本流程：**选文件 → 诊断 → 调处理链 → 预览 A/B → 导出**。

如需读取 mp3 / m4a / flac / mov / mp4，本机 PATH 中需有 `ffmpeg`；否则请先转成 WAV。

## 主要算法实现

### 处理链

`sep → ai → m5 → m1 → m2 → m3 → m4 → m6 → dyneq`

| 模块 | 作用 | 当前算法 |
|---|---|---|
| **sep** 源分离 | 置于所有后处理之前，分级处理人声/低频/打击 | HPSS 滑动中值（时间核 25 帧 / 频率核 31 bin）；`nmf` 为秩 4 固定先验字典投影；四路掩码逐 bin 归一使**和恒为 1**（全增益恒等） |
| **ai** 重建 | 低频/人声 AI 重建 | **接口预留**，`process` 透传并在 stats 标记 `interface_only` |
| **m5** 修复层 | 去削波 / 交流声 / 场地混响与共振 / 泵动 | Hermite 削波重建；市电陷波 Q=30 且**按陷波半带宽自适应换算 bin 数**（只做 1、2 次谐波）；**`dereverb` 场地去混响 / 中低频抑共振**：70-600Hz 内**压多少**由整带衰减深度定、**压谁**由逐 bin 衰减门定（持续乐音 bin 自身平坦 → 受保护）、**额外量**由该 bin 相对跨频中位数基线的突起定（窄带模态高、宽带混响低），上限 −12 dB；反向 AGC 泵动修正（±9 dB）。<br>（原 `denoise` 最小值统计谱减 + `floor_db` 已于 2026-10-14 删除，由 `dereverb` 取代） |
| **m1** 中低频重建 | 提密度、不提浑 | **静态 + 自参考双层频段增益**：`weight` 静态 +9 dB@30-150Hz 叠自适应动态；`density` 静态 +6 dB@40-250Hz 叠最多 +12 dB 向上压缩；`punch` 用**自适应通量阈值**（本轨 p55）最多 +9 dB；`tame` 驻波下压最多 −12 dB；`sub` 用**包络驱动次谐波**（20-80Hz 载波相干 tile）+ <70Hz 低架；**`ring` 低频混响衰减**：25-180Hz「过去峰值 vs 未来谷值」拖尾检测，只砍衰减段（攻击/持续音保护）最深 −12 dB，治驻波嗡嗡声；**`dive` 下潜重建**：20-50Hz 载波相干合成（源 = 2f/3f 包络）+ 4 dB 低架，补回相机麦滚降缺失的次低频（20-40 Hz 实测 +12 dB） |
| **m2** 中高频补充 | 补信息、不抬噪 | `air` 用 **dB 目标制**倒谱包络外推（拉满 = ext_hz 以上带内能量 +18 dB，交叉淡化在 `ext_hz` **以下** 1/3 八度，扩展上界收在 18 kHz）；`detail` 用**相位加倍（2θ）生成真二次谐波** + 4-8 kHz 高架；`dehiss` 压制**贴近噪声底**的 bin（最多 −24 dB） |
| **m3** 人声优化 | 去掩蔽 / 去混响 / 去刺 / 齿音 | 四个子处理器全部改成**自参考分位激活**（clarity p55→p92、harsh p75、ess p85，保证任何素材上参数都有权威度）；room 为谱域晚期混响统计抑制（前视窗最小值）；ess 用「一帧到位 + hold + release」专门咬短脉冲 |
| **m4** 声场扩展 | 宽度 / 纵深 / 旋转 | 分频段 M/S 宽度曲线（幅度域、保相位）；纵深用 **M 的全通去相关分量注入 S**（一级全通级联，幅度平坦不染色）+ **(M,S) 联合功率归一**（总电平不变、S/M 比真实上升）；M/S 旋转矩阵 |
| **m6** 母带响度 | 响度达标、真峰限制 | BS.1770-4 K 加权与门控；LRA glue 沿分位数扫参考点取最接近目标的曲线；4× 过采样前瞻真峰限制器（5 ms 前瞻 / 1 ms 网格 / attack 1 ms / release 80 ms） |
| **dyneq** 动态 EQ | 最后一步精修 | RBJ peaking 静态曲线（精确）+ 软边频段掩码近似动态曲线；`static` / `up` / `down` 三模式 |

分级路由（`sep.on` 且 `routing=graded`）：**m1 只作用于 backing，m3 只作用于 vocal，m2 作用于两路后合回**，m5 按轨执行。

### 关键实现

- **即时 A/B**：两条完整音轨并行播放，切换 = 两路增益 6 ms 交叉；`auMain` 是真正 transport，原片轨每帧与它对齐（偏差 > 35 ms 拉回）；两轨路由进同一 `busIn`，实时 EQ 与频谱分析看到的始终是正在听的一条。原片轨只在进入对比时才解码，退出即暂停。
- **调音台与干湿比**：引擎渲染时捕获每段贡献量 `delta = out − in`（float16），满足望远镜恒等 `原片 + Σ 贡献量_k == 处理后`（实测最大偏差 ≤ 3e-4）。推子只缩放贡献量：`混音 = 原片 + Σ 增益_k × 贡献量_k`（`POST /api/remix`，约 30 ms，**不重跑处理链**）。干湿比 `mix` 在段边界做 `out = (1-mix)·in + mix·proc(in)`，与模块参数分离，每模块独立。
- **三层缓存**：解码缓存键 `(绝对路径, mtime_ns, size)`，进程内 LRU 上限 1.5 GB；输入统计缓存 8 条；转码缓存键 `sha1(绝对路径\|mtime\|size)[:10]`，**落盘跨重启有效**。键里带 mtime/size，源文件被替换会自然失效。
- **HTTP 接口**：本地服务提供 `state` / `models` / `list` / `analyze` / `job` / `audio` / `remix` / `clips` / `cache` / `export` 等接口；`/api/audio` 支持 HTTP Range（206 / 416 / `Accept-Ranges`）与 HEAD，按块流式发送。完整契约见 [`spec/API.md`](spec/API.md)。
- **进度与 ETA**：成本模型 = 每段 ms/秒音频先验 + 完成后 EWMA 自更新，再按实际速率缩放。

### 算法参考

HPSS（Fitzgerald 2010）、NMF（Lee-Seung 2000）、最小值统计噪声估计（Martin 2001）、谱域晚期混响抑制与衰减段检测（统计式去混响思路）、WPE 思路的统计简化（Nakatani 2010）、缺失基频心理声学、RBJ 双二阶滤波器、Linkwitz-Riley 分频思路、ITU-R BS.1770-4 响度、EBU R128 / True Peak、BS.775 5.1 上混矩阵、M/S 声场处理（Fairlight 思路）。

## 注意事项

### 参数与导出

- **默认参数**是用户实听冻结的一版初始值，不是自动校准结果；改动入口在 `livefix/engine.py` 的 `DEFAULT_CONFIG`。该表由 `tests/test_engine.py` 的 47 项断言保护，误改会立刻测试失败。
- **`m6 = OFF` 不等于导出不归一**：`exporter` 按 `export.loudnorm=true` 独立做响度归一与真峰保护。但处理链内因此**没有真峰限制器**，峰值很热的素材可能过 0 dBFS。
- **真峰（True Peak）实现有误**：`measure._true_peak_env` / `m6._env_oversampled` 用「频谱镜像 + 基带 ×2」而非零填充插值，最坏情形实测低估 **3 dB**。因此「真峰安全导出」在极端素材上不可靠，**未修**。
- **m4 加宽的单声道代价**：宽度拉满时相关性 0.92 → 0.68，折叠成单声道会有相位抵消损失；`stats.m4.mono_fold_db` 已上报，但 UI 尚未显示。

### 运行与资源

- **长素材内存随时长近似线性增长**：8.4 分钟实测峰值 5.89 GB，30 分钟立体声 48 k 约需 20 GB。根因是 `m6` / `sep` 整轨单次执行。
- **诊断层不完全可靠**：市电检测阈值过低，50 Hz / 60 Hz 族信号都可能超阈而被音乐内容误判；高频截止判据在门限附近会抖动。
- **`cache/` 是可再生中间产物**：包含预览 / 原片 WAV、贡献量 npz、转码结果与 A/B 片段，默认自动回收；`dry_run` 默认 `true`，不显式传 `false` 只报告不删。
- **测试是独立脚本**，不是 unittest / pytest 用例，所以 `python -m unittest discover` 会报 ImportError，这是预期行为。**18 个脚本**全部自带 PASS/FAIL 输出与退出码：

  ```powershell
  Get-ChildItem tests\test_*.py | ForEach-Object { python -X utf8 $_.FullName }
  ```

- **训练 / 评判素材不在仓库里**：`源1.wav` / `调整1.wav` / `音源前.wav` 属于数据集，不随仓库分发；`origin/` 下的 `judge_chain.py` 已丢失，那批扫描脚本目前不可运行，按 `bench.py` 接口重写约 20 行适配器即可恢复。
- **契约与实现可能漂移**：m3 的部分扩展参数（clarity_f0 / harsh_thr / ess_thr 等）未写进 `spec/API.md §4`；`spec/CORE.md` 与实际模块的分块包裹范围不完全一致，以实现为准。
